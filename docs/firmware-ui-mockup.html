0x2A7C

Trình cập nhật phải hiện CheckSum : 0x2A7C. Đúng thì bấm Start. Khác thì đóng nó lại, đừng bấm. Ứng dụng không bấm Start thay bạn.

  • Bản sao lưu: 2026-11-01_1432_truoc-nap (4 layer). Trình cập nhật không ghi vùng layer, sao lưu để chắc.
  • Trong lúc nạp bàn phím sẽ ngắt kết nối và cắm lại. Nếu kẹt, trình cập nhật vẫn nhận nó ở chế độ nạp (0C45:7040).
